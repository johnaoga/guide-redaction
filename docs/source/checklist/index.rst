.. _checklist:

*************************************************************************************************
Check-list avant soumission
*************************************************************************************************

Avant de soumettre votre mémoire, parcourez cette check-list et **cochez chaque
point que votre document respecte**. Elle reprend, dans l'ordre, les règles
du :doc:`guide <../guide/index>`.

Lorsque vous cliquez sur **Vérifier ma check-list**, chaque point non coché est
signalé avec un lien vers la section du guide qui en parle.

.. important::
   Soyez honnête : cette check-list n'est utile que si chaque case cochée
   correspond à une vérification réellement faite dans votre document.
